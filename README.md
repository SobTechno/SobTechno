## 🚀 Featured Project: Routine Task (روتین تسک)

A study planner & habit-building app (Persian, RTL, installable PWA) with a
production-style backend: smart reminders, reading tracker, levels roadmap,
leaderboard, and a VIP plan with online payments.

| | |
|---|---|
| 🔐 **Auth** | `scrypt`-hashed passwords with salt, signed HMAC session tokens |
| 💳 **Payments** | Zarinpal gateway (sandbox + production), server-side verification, replay protection |
| 🛡️ **Security** | Rate limiting, input validation, payload limits, strict CSP/HSTS headers |
| 🏆 **Leaderboard** | Server-computed stats with anti-cheat caps, cached public API |
| 🗄️ **Data** | Serverless API with key-value storage, account deletion for privacy |
| 📲 **PWA** | Offline cache, notifications with action buttons |

**Stack:** Node.js · Serverless Functions · Vanilla JS · HTML/CSS · Service Workers

🔗 [**View the repository**](https://github.com/sobhan/routine-task)
